# OSINT Agent-X — Complete Project Reference

## Overview
Agentic AI-powered OSINT (Open Source Intelligence) tool with 3 UI modes, an agentic AI loop, Instagram/Python tools, DNS/GeoIP scanning, cross-platform username search, and a sandboxed terminal for the AI agent.

## Architecture & Data Flow

### Web UI Flow
```
User (browser) → localhost:3000 → Vite dev server (HMR)
  → React App (TerminalApp.tsx)
  → POST /api/osint/scan  →  Express (rate limit 10/min, CSRF check)
      → resolveTargetData (DNS + MX + GeoIP)
      → createAIProvider().generateContent (Gemini/OpenRouter/Zen)
      → Parse AI JSON response → return report
```

### CLI Flow (Ink)
```
User keyboard → useInput() hook → handleCommand()
  → runIG() / runScan() / runSherlock() [via orchestrator]
  → streamAI() → AI streaming response → pushLog()
```

### Agent Chat Flow
```
User → startAgent() → function calling loop (max 15 turns)
  → AI decides which tool to call
  → tool.execute(args, ctx) → push result → AI decides next action
  → loop detection (3× same call) / sliding window rate limiter (5 destructive/min) / session timeout (5 min)
```

## AI Provider System (`tools/ai-agent/provider.ts`)

| Provider | Class | API Base | Env Key |
|----------|-------|----------|---------|
| Gemini | `GeminiClient` | `@google/genai` SDK | `GEMINI_API_KEY` |
| OpenRouter | `OpenAICompatibleClient` | `https://openrouter.ai/api/v1` | `OPENROUTER_API_KEY` |
| Zen | `OpenAICompatibleClient` | `https://opencode.ai/zen/v1` | `ZEN_API_KEY` |

Both implement `AIClient` interface:
- `generateContent(params)` — standard request with tools/function-calling support
- `generateContentStream(model, contents, systemPrompt, onToken)` — SSE streaming

## Instagram Python Tools (`tools/ig/`)

All 5 scripts share:
- Session: `/tmp/.agent-x-ig-session.json`
- Auth: `IG_SESSIONID` (cookie) or `IG_USERNAME` + `IG_PASSWORD`
- `cl.delay_range = [3, 7]`, `cl.request_timeout = 30`
- Output: JSON via stdout (custom `out()` function)

## Terminal Sandbox (`tools/terminal/index.ts`)

### 10 Tools
| Tool | Description | Requires Confirm |
|------|-------------|:--:|
| `read_file` | Read file content | No |
| `list_dir` | List directory entries | No |
| `grep_file` | Regex search in file | No |
| `glob_files` | Glob pattern matching | No |
| `write_file` | Write content to file | Yes |
| `append_file` | Append to file | Yes |
| `make_dir` | Create directory | Yes |
| `delete_file` | Delete file/dir | Yes |
| `run_command` | Execute shell command | Yes |
| `get_cwd` | Get current directory | No |

### Security Measures
- **Path traversal**: `realpath()` + boundary check (not just string prefix)
- **Restricted files**: `.env`, `.env.*`, `.agent-x-audit.log` — blocked from read/write
- **Command allowlist**: 29 commands (`cat`, `ls`, `grep`, `find`, `python3`, `git`, `npm`, etc.)
- **No shell**: `spawn()` instead of `exec()`, `shell: false`
- **Absolute path blocking**: Only `/usr/`, `/bin/`, `/tmp/` paths allowed in args
- **Headless mode**: All commands auto-blocked
- **Confirmation**: Every destructive op requires user confirm

## Agent Runtime (`tools/ai-agent/index.ts`)

### Features
- **History trimming**: At 100 messages or 100k tokens, trims oldest with summary
- **Retry**: 2 retries for rate_limit/timeout, 1 retry for `ig_*` tools
- **Loop detection**: Same tool+args 3× in a row triggers halt
- **Rate limiter**: Sliding window — max 5 destructive ops per 60s
- **Session timeout**: 5 minutes total
- **Audit log**: `/tmp/.agent-x/audit.log` — masked sensitive content
- **Error classification**: `rate_limit`, `timeout`, `not_found`, `auth_error`, `unknown`
- **Investigation tracking**: `init_investigation` → `add_finding` → `get_investigation_summary`

## API Endpoints (`server.ts`)

| Method | Path | Rate Limit | Auth | Description |
|--------|------|:----------:|:----:|-------------|
| GET | `/api/status` | None | No | AI provider health check |
| POST | `/api/admin/reload-provider` | None | No | Reload .env + recreate provider |
| POST | `/api/osint/scan` | 10/min | CSRF | Full OSINT scan (DNS + GeoIP + AI analysis) |

### Security
- **CSRF**: Only allows `localhost:PORT` and `127.0.0.1:PORT` origins
- **Rate limit**: 10 requests/minute on `/api/osint/scan`
- **No stack leak**: Generic error messages to client
